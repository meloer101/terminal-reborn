# TerminalReborn 产品简报

## 定位

为同时运行多个 Claude Code / Codex 的开发者打造的 macOS 终端。

保留 agent 原生的终端界面，在其之上补齐四件事：**能正常编辑的输入框**、**一眼可见的 agent 状态与即时回复**、**worktree 从创建到合并的完整链路**、**带 agent 状态的 git 全景**。并且外观可以深度定制，对中文用户友好。

- 目标用户：同时跑 3–10 个 agent、在多个 worktree 间并行开发的 vibe coder。
- 一句话：*终端还是那个终端，但你终于管得住这一群 agent 了。*

## 设计原则

1. **终端优先**：终端内容是主角，界面其余部分退后，不与之争夺注意力。
2. **只在需要你时打扰**：状态分级。"等你处理"是唯一高亮的状态，其余保持安静。
3. **键盘可达**：所有高频操作都有快捷键，数字键直接作答。
4. **信息密度而非装饰**：用排版层级、对齐与分隔线组织信息，不用卡片堆叠和装饰性元素。

## 对象模型

```
Project（git 仓库）
 └─ Worktree（分支 · 路径 · 基线分支 · 改动统计）
     └─ Session（agent: Claude / Codex / Shell · 状态 · 当前任务 · 当前动作）
```

Session 状态：`运行中` · `等你处理`（权限 / 提问）· `已完成·未读` · `空闲` · `出错` · `已退出`

## 界面结构

| 区域 | 内容 |
|---|---|
| 左侧栏 | 项目 › worktree › 会话三级树；顶部是"等你处理"队列；底部是设置入口 |
| 主区 | 会话标题栏（agent、分支、状态、耗时）→ 终端 → 输入栏 |
| 右侧面板（可收起） | 变更（diff 审阅）· 图谱（提交图 + worktree）· 合并 |
| 全局 | ⌘K 命令面板 · ⌘N 新任务 · ⌘, 设置 |

## 功能

| # | 功能 | 要点 |
|---|---|---|
| F1 | 输入栏 | 原生多行编辑（可选中删除）、中文输入法安全、按会话保存草稿、拖入图片/文件、`@` 引用文件；输入为空时 Esc、↑↓、⇧Tab 直接交给 agent |
| F2 | 状态侧栏 | 每个会话显示：状态、任务标题、当前动作（"编辑 auth.ts"）、`+N −M`、耗时；"等你处理"置顶；系统通知与 Dock 角标 |
| F3 | 即时回复 | 权限请求与选项提问显示在输入栏上方，可点击或按数字键作答；也可以在侧栏行内直接回复，不必切换会话 |
| F4 | Worktree | 新任务一步创建分支、worktree 和 agent；支持 `.worktreeinclude` 与 setup 脚本；本地合并（merge / squash / rebase）先做冲突预检；冲突可交给 agent 解决；合并后清理 |
| F5 | Git 全景 | 提交图上标出每个 worktree 的位置及其 agent 状态；点击跳转到对应会话；右键合并 |
| F6 | Diff 审阅 | 按文件查看改动；行内评论可一键发给 agent |
| F7 | 外观 | 主题、英文/中文字体分别设置、字号与行高、背景（纯色/渐变/图片）、侧栏毛玻璃，全部实时预览 |

## 核心链路

**L1 开新任务**
⌘N → 选项目 → 写任务描述（自动生成分支名，可修改）→ 选 agent 与基线分支 → ↵
→ 后台创建 worktree、复制被忽略文件、运行 setup → 启动 agent 并送入首条 prompt → 侧栏出现该会话，状态为"运行中"

**L2 输入与发送**
在输入栏编辑 → ↵ 发送（⇧↵ 换行）→ 以 bracketed paste 写入 → 确认 agent 已收到 → 单独发送回车。agent 忙时发送 = 插话（steer）。

**L3 被需要时**
agent 请求权限或提出问题 → 侧栏该会话变为"等你处理"并置顶，系统通知 →
在输入栏上方的选项条点击，或按 1/2/3 作答（也可在侧栏行内作答）→ agent 继续运行

**L4 审阅与合并**
会话完成（已完成·未读）→ 右侧"变更"查看 diff → 有问题就写行内评论发回 agent；没问题就点"合并"
→ 预检（是否落后基线、是否有冲突）→ 选合并方式 → 合并到基线 → 选择是否删除 worktree

**L5 冲突**
预检发现冲突 → 列出冲突文件 → "交给 agent 解决"（自动生成说明并发送到该会话）或"中止"

**L6 Git 全景**
打开"图谱" → 看到 main 与所有 worktree 分支的走向、每个 worktree 的 agent 状态、领先/落后 → 点击节点跳转到会话 → 右键合并或 rebase

**L7 外观定制**
⌘, → 外观 → 选主题 / 英文字体 / 中文字体 / 字号行高 / 背景 → 右侧终端预览实时变化
