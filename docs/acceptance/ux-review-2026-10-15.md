> 日期：2026-10-15 · 版本：v0.1.1（main `3fe24d2`）· 方法：用 Playwright 启动构建版（全新空档案 + 夹具数据），在 1440×900 和最小窗口 960×600 下走查 25 个状态并截图；对照 Figma 02 号屏幕（`16:178`）、PRD §4、第二阶段计划的 B 类条目，以及竞品的最新公开资料（2026-05 至 2026-10 的 changelog 和对比页）。

## 0. 结论

**视觉和核心交互已经接近成熟产品的水准，但产品还没有“闭环”，也还没有“没有死角”。**

- 好的部分：克制的视觉、中英文排版、输入栏、选项条、设置页预览都做得很好。截一张静态图拿出来，不输 Conductor 或 Orca。
- 差距不在“好不好看”，而在三件事：
  1. **任务做完之后，没有地方可以去。** 侧栏写着“已完成，等你审阅”，但右侧面板是空白的，也没有合并入口。所有主流竞品都在应用内完成了“审阅 → 合并 / PR”。这是目前最大的差距。
  2. **到处是走不通的路。** 空白的右侧面板、点了没反应的“…”、设置里 4 个“即将推出”、最小窗口下布局塌掉。成熟产品的标志之一，是用户点到的每个地方都有下一步。
  3. **第二阶段 B 类（日常体验）一条都还没做。** 本次走查中 B1–B18 的问题基本都能复现。

## 1. 值得保留的部分

- **设计语言落地准确**：零彩度中性色、只用颜色表达状态、用发丝线和字重分层。侧栏的 `+42 -18`、`4m` 用等宽字体对齐，深浅主题都干净（[02-main](ux-review-2026-10-15/02-main.png)、[07-stale-row](ux-review-2026-10-15/07-stale-row.png)）。
- **输入栏**：浮动卡片；提示文字按状态切换（“智能体运行中，↵ 发送会排队”）；运行中出现停止按钮；中英混排换行正常。这是相对 Orca / Superset 默认 TUI 输入的核心优势。
- **选项条**：选项带编号，说明文字显示在选项内，数字键可以直接作答（[03-permission](ux-review-2026-10-15/03-permission.png)）。
- **设置 · 外观**：中英文字体分开设置，实时预览里有“中文宽度 / ASCII”对齐格。竞品里还没有一家提供这个（Orca 1.3.41 才把 IDE 字体和终端字体分开，仍然没有中文字体选项）（[09-settings](ux-review-2026-10-15/09-settings.png)）。
- **⌘K**：会话行带状态图形、所属项目和当前动作，分组清楚。
- **可靠性底座**（2a）：关窗隐藏、退出确认、重启后恢复对话。这些是“敢当主力工具”的前提，竞品也是近半年才补上（cmux 0.65 的会话恢复）。

### 4.2 差距的本质

1. **闭环（最大的差距）。** 竞品的价值链是“开任务 → 跑 → 审阅 → 合并 / PR”；TerminalReborn 目前停在“跑完”。Superset 在对比页里直接把 cmux 定位成“只是终端”，理由就是缺少审阅链路。在 M4 落地之前，TerminalReborn 在评测里会被归到 cmux 那一类。
2. **“没有死角”的打磨程度。** 成熟产品的特征：每个状态都有下一步（出错有修复入口、完成有审阅入口），没有摆设控件，窄窗口不塌，菜单栏和 ⌘K 能覆盖所有操作。Conductor 连“等所有 agent 空闲后再重启更新”这种细节都做了。这部分不需要新功能，只需要把 B 类做完。
3. **生态广度。** 手机端（Orca / Superset / cmux 都有）、内置浏览器 / Design Mode（Orca、Superset 在 2026 年下半年同时推出）、8 种以上 agent 加自定义 CLI。这些属于 PRD 的非目标，或安排在 M6，短期不必追。但“自定义 agent 命令”的成本很低，值得提前做。
4. **仍然握在手里的差异化。** 中文优先（字体、输入法、文案）；输入栏叠加在原生 TUI 上；本地合并；**带 agent 状态的 Git 图谱目前没有任何一家做**。后两项的前提都是 M4 / M5 先落地。

## 5. 建议的顺序

1. **2b · “没有死角”（约 1 周，发 v0.2.0）**：P0 #1–#4 + P1 #5–#12，即计划里的 B 类加本报告新增的两条。原则：未完成的入口一律隐藏；每个状态都有下一步。
2. **M4 先切一个最小的闭环**：只读的“变更”面板（对比基线的文件列表 + diff）+ 行内评论发给 agent。这一步先把右侧面板填上，并且能把“已完成，等你审阅”直接链接到面板。之后再做新建任务（worktree）和本地合并。
3. **M5 图谱**：这是唯一没有竞品做的方向，宣传点就放在这里。
4. 低成本、高收益的顺手项：自定义 agent 命令（设置 → Agent）；用“新手引导 + 样例项目”替换首屏的空白。

## 6. 本次没有覆盖的内容

- 真实 agent 的完整对话（走查用的是夹具会话 + 注入的提示；真实链路见 2a 验收）。
- 系统通知、Dock 角标、侧栏毛玻璃、搜狗 / 系统拼音输入法、VoiceOver。
- PRD §1.3 的性能指标（冷启动、10 个会话时的输入延迟、内存），仍是 D1 的待办。
- **更正（2026-10-16）**：走查中出现的终端字形错乱，当时判断为测试脚本的副作用，这个判断是错的。它是真实的 P0 缺陷。原因是：设置页的预览终端与主终端共用同一张 WebGL 字形图集，预览清空图集后，主终端仍在使用旧的字形坐标。复现步骤：打开并关闭设置 → 终端再有一次输出 → 之前的所有行都变成乱码或黑块。
