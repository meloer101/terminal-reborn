# 第二阶段：从“能用”到“可以天天用”

> 日期：2026-10-14 · 依据：代码审计（只读）、打包版真实走查（4 次真实 Claude 对话）、PRD 与竞品调研对照、M1–M3 验收遗留项
> 现状：v0.1.0（草稿）。核心链路已通：真实终端、桌面级输入栏、hooks 驱动的状态、权限 / 提问一键作答、⌘K、外观设置、Codex 适配。

## 0. 结论

主链路是好的，但离“放心当主力工具”还差三类东西：

1. **信任感**：现在一个误操作就可能让所有 agent 丢掉上下文（⌘Q / ⌘R / 关窗口不确认、重启后对话不恢复、agent 退出后输入栏把话当命令发给 shell）。这是最优先的。
2. **日常顺手**：会话分不清、不能改名、新会话不聚焦、快捷键缺口、空状态和半成品控件、窄窗口布局、通知信息量不够。
3. **差异化功能**：右侧“变更 / 图谱”面板还是空的——这正是 PRD 里的 M4（worktree 全链路 + diff 审阅）和 M5（带 agent 状态的 git 图谱），也是我们和竞品拉开差距的地方。

建议顺序：**A 可靠性 → B 日常体验 → C 差异化功能（M4 → M5）→ D 发布质量**，A+B 完成后发 v0.2.0。

## B. 日常体验

**会话识别与管理**
- B1 会话不能改名；同项目下多个“Claude Code”无法区分 → 双击 / 右键 / F2 改名，重名自动编号。
- B2 侧栏第二行显示完整路径，信息量低 → 改为最近动作或最后一句回复；有 worktree 后显示分支。
- B3 “等你处理”队列里看不出项目；会话被提到队列后原项目只剩空标题 → 队列行加“项目 ›”，原位置留一行淡色占位。
- B4 “已完成·未读”只有一个绿点没有文字（违反“状态不只靠颜色”）→ 加“已完成 · 未读”和最后一句回复。
- B5 时间显示的是会话开始至今 → 运行中显示本轮用时，等你处理显示“已等 3m”。
- B6 通知只有标题和状态 → 标题“项目 · 会话”，正文为问题或最后一句回复；多会话同时完成时合并。

**焦点与键盘**
- B7 新建 / 打开会话后键盘焦点不在终端或输入栏，信任弹窗不知道要点终端 → 自动聚焦；有阻塞弹窗时聚焦终端并提示按键。
- B8 PRD 里的快捷键缺口：⌘\ 侧栏、⌘⌥B 面板、⌘W 关闭会话、⌘F 终端内搜索、⌘+ / ⌘- / ⌘0 字号；侧栏行不显示 ⌘1–9；菜单栏没有“文件 / 会话”菜单且中英混排 → 补齐并在菜单、⌘K、侧栏里显示。
- B9 侧栏收起后看不到其他会话在等你 → 标题栏加“N 个等你处理”小标签，点击跳转。

**空状态与半成品**
- B10 关掉最后一个会话后主区是空的但看起来能输入 → 主区空状态（⌘N 新建 · ⌘O 打开项目）。
- B11 无功能的控件：标题栏“…”、输入栏“@”只插入一个 @、右侧面板空白、设置里四个“即将推出” → 未完成前隐藏；“@”做成真正的文件选择器。
- B12 选项条：“总是允许”没说明允许什么；“其他…”输入框按 Esc 后仍显示，输入落到下方输入栏导致发送失败；两个输入框并存让人困惑 → 标明范围、Esc 收起、提问期间把输入栏的输入引到回答框。

**布局与外观**
- B13 最小窗口打开右侧面板时主区被挤到 136px，面板开关被盖住无法关闭 → 主区最小宽度，窄窗口自动收起侧栏或让面板浮层显示；面板内加关闭按钮。
- B14 浅色主题配渐变背景时文字几乎看不见（渐变默认色不随主题）→ 默认色随主题；按背景亮度校正前景或给出对比度提示。
- B15 设置：英文字体列表混入非等宽字体、中文字体 51 个没有分组、没有“恢复默认”、预览不显示背景 → 按字宽筛选等宽字体、中文字体分组 + 搜索、加恢复默认、预览渲染背景。
- B16 用语统一：打开项目 / 添加项目、终端 / Shell、变更面板；⌘K 会话顺序与侧栏不同。
- B17 走查中出现过一次主题自己变成深色且写进了设置，未能复现 → 排查 `applyTheme` 的写入路径。

**终端本身**
- B18 无终端内搜索（⌘F）、无屏幕阅读器模式；WebGL 一次丢失后永久退回慢速渲染 → 加 search addon 与查找栏、可选读屏模式、可见时重试 WebGL。
- B19 待验证：终端选区 ⌘C 复制、⌘V 粘贴的完整行为。

## C. 差异化功能（原路线图）

- **M4 Worktree 全链路 + Diff 审阅**（PRD F4/F5，Figma 03/05/06）：新建任务（分支 + worktree + 首条 prompt）、`.worktreeinclude`、setup 脚本、本地合并预检、merge / squash / rebase、冲突交给 agent、合并后清理；变更面板 + 行内评论发给 agent。右侧面板从此有内容。
- **M5 Git 图谱**（PRD F6，Figma 04）：自研 lane 图，每个 worktree 的位置和对应 agent 状态，点击跳会话，右键合并 / rebase。
- **M6 深化**：侧栏内联回复（不切换会话直接作答）、PTY 守护进程（应用重启 agent 不中断）、GitHub PR、checkpoint、主题导入、多会话总览。

## D. 发布质量

- D1 性能基线：10 / 20 个会话的内存、输入延迟、冷启动（PRD §1.3 指标目前都没测）；隐藏会话的输出处理、侧栏重渲染、渲染包 1.45 MB 未拆分。
- D2 可访问性：设置和 ⌘K 弹窗没有焦点锁定，侧栏状态变化没有朗读。
- D3 测试：真实 agent 的端到端测试和打包测试不在 CI 里跑（可做成每晚任务）；补故障注入测试（杀掉终端进程、删掉 socket、命令不存在）；减少固定等待。
- D4 安全收紧：CSP 补 `base-uri` / `object-src` / `form-action`，权限请求默认拒绝；IPC 事件里不再传完整的写入文件内容。
- D5 签名公证 + 自动更新：需要 Apple Developer 账号。
- D6 代码健康：测试钩子进入了正式包、少量重复常量、已废弃别名。

## 已确认的决定（2026-10-14）

- 顺序：A 可靠性 → B 日常体验 → C（M4 → M5）→ D。
- 点窗口关闭按钮只隐藏窗口，agent 继续运行；⌘Q 才退出，有运行中 / 等你处理的会话时先确认。
- 重启后不自动拉起所有 agent：会话在第一次被切到时用 `--resume` 接上原对话，未启动前侧栏标“未启动 · 点击恢复”。
