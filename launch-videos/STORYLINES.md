# Storylines

Three separate films (2026-10-22): A in `a-waiting/` (the main launch film), B in `b-question-marks/` (short teaser), C in `c-three-answers/` (feature film).

The one thing: Wavi tells you which of your agents is waiting on you, so you answer it now instead of 23 minutes later.
Viewer: a developer on macOS running several Claude Code / Codex agents, each on its own worktree.

## A — The one that's waiting (picked)

- Device: life before and after. Form: split screen to one.
- What the viewer sees: eight terminals stream agent output; one has been stuck on a permission prompt for 23 minutes and nobody noticed. The eight panes fold into Wavi's sidebar, where only that one row lights up; ⌘J, answer, it keeps going, review, merge, and the git graph shows every branch coming home.
- First 2 s: a 4×2 wall of terminals filling the frame, all streaming, except one pane whose Claude prompt "Do you want to proceed?" sits still.
- Beats: hook (the wall) → tension (focus hops pane to pane, misses it; punch in: it waited 23 minutes) → reveal (panes fold into the sidebar; only it lights up) → proof (⌘J · answer · read the diff · ⇧⌘M merge) → payoff (git graph, every branch merges in) → claim (One person, many threads.) → end card (the ten "?" are answered, WAVI, Download for macOS).
- Look: the app's own dark UI at 2× on its #050505 ground; magenta #ff5fb0 only on what waits on you; Archivo for titles; the site's CRT tube for the end card.
- Sound: key ticks on each focus hop, near silence on the punch-in, a single notification when the row lights, bed opens from the reveal, riser into the last merge.

## B — Ten question marks

- Device: type carries the argument. Form: match cuts.
- The site's CRT tube: ten magenta "?" flicker, one per waiting agent. Press J and one collapses to "·"; the dot becomes the sidebar's status glyph, the glyph a branch node, the node the merge dot on main. All ten answered: ALL RUNNING, then BRANCH OUT. / MERGE IN. on the beat.
- First 2 s: the tube warming up, ten "?" rolling through snow.
- Beats: hook (ten ?) → answer one → glyph → node → merge → ALL RUNNING → BRANCH OUT. MERGE IN. → end card.
- Look: the site's noise facade: CRT scanlines, Bodoni Moda + Archivo, magenta.
- Sound: tube hum, a degauss thunk per answered "?", synth beat.
- Risk: the least proof of the product; reads best for people who saw the site.

## C — One task, three answers

- Device: one object across worlds. Form: one continuous take along the git graph.
- The task "Get checkout's first paint under 2s" sits on main and splits into three branches (Claude, Claude, Codex). The camera travels along them past each worktree's terminal, the conflict radar flashes where two touch the same file, one stops to wait on you, then the three land side by side in Compare (diff size, checks), the best one merges and the rest are archived.
- First 2 s: the task card on the main line, splitting into three.
- Beats: task → fork → work → conflict → wait → compare → merge → graph → end card.
- Look: the graph's lines as the carrier on black; colour only for status.
- Sound: one rising pad; a tick on each fork and merge.
