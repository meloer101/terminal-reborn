同时跑十个 agent， 只在需要你时叫你。

Wavi 是为并行运行 Claude Code 和 Codex 而做的 macOS 终端。agent 的原生界面原样保留，Wavi 补上它们缺的：谁在干活、谁在等你、每个 worktree 怎么合回主干。

八个 agent，
同时在跑。

每个会话在自己的 worktree 里干活。侧栏告诉你它在哪，总览告诉你现在该做什么。

有的做完了，
有的卡住了。

状态来自每次启动时注入的 hooks，一秒内同步到侧栏、总览、系统通知和 Dock 角标。每种状态都有自己的形状和文字，不只靠颜色。

只有一个，
在等你。

“等你处理”是整个界面里唯一高亮的颜色。按 ⌘J 直接跳过去，在终端里作答，agent 接着跑。

终端就是全部界面。

Wavi 不重画聊天窗口。Claude Code 和 Codex 的界面原样运行，你的每个按键都直接进入它们；关掉窗口、按 ⌘Q，agent 也照样在后台跑，回来时接上同一个进程。

从开工到合并，
不离开 Wavi。

一个 agent 一条分支、一个 worktree。图谱上标着每条分支此刻是哪个 agent、在做什么。

  1. 1

    新建会话 ⌘N

    项目、基线、agent 都有默认值，什么都不改直接回车。

  2. 2

    后台建 worktree

    fetch、建分支、复制被忽略的文件，再启动 agent。

  3. 3

    各干各的

    每条分支一个 agent，互不踩脚。

  4. 4

    审阅变更

    右侧栏看对比基线的 diff，或者点“让 agent 审阅”。

  5. 5

    预检后合并 ⇧⌘M

    先在内存里试合并。有冲突，就把说明放进输入行，由你按回车。

  6. 6

    收尾

    合并后选择是否删除 worktree，分支留着。

Wavi 不替你花 token。

只有你点了按钮，Wavi 才会给 agent 发消息，按钮上写明会发什么。可能很贵的任务只放进输入行，等你看过、自己按回车。

没有账号，没有遥测
Wavi 本身不用注册，也不用登录。有新版本时提示一次，点开是发布页，不自动下载，不自动安装。
不碰你的全局配置
hooks 在每次启动 agent 时注入，不写进 ~/.claude 和 ~/.codex。也不绕过 agent 的 hook 信任：Wavi 只放行自己注入的那几条，仓库和插件里的 hook 照旧由 agent 把关。
归档不用 git stash
归档把 worktree 里没提交的改动存进 Wavi 自己的 refs/wavi/archive/…，你的 stash 列表、分支、暂存区和 git 配置都不动。
不替你发消息，不替你恢复会话
重启电脑后，会话停在“未启动”，等你打开才用 --resume 接上原对话。发给 agent 的每一句，都来自你按的回车或你点的按钮。
关掉窗口，agent 照跑
⌘Q 之后会话在后台继续运行，重新打开接回同一个进程和屏幕。
开源，MIT
每一行代码都在 GitHub 上，欢迎读，也欢迎改。

手不用离开键盘。

  • ⌘J下一个需要你的会话
  • ⌘N新建会话
  • ⌘⇧A总览
  • ⌘K跳转到会话、项目或操作
  • ⇧⌘M合并到基线
  • ⌘1–9切换会话
  • ⌘B收起侧栏
  • ⌘F在终端里查找
